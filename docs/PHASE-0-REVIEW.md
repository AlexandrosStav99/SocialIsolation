# Phase 0 review

Review date: 2026-09-20. Scope: PR #2, `phase-0/baseline-hardening`, against `TALKPOINT-MVP-SPEC.md` and `IMPLEMENTATION-PLAN.md`. This is baseline hardening, not completion of the MVP or approval for real-world deployment.

## CI root cause and correction

The inherited failing run 35505934895 passed lint but failed TypeScript because `SpeechRecognitionLike` omitted `onerror`. Adding the missing property reproduced a clean build locally. Final review then removed the legacy microphone integration: browser speech recognition can transmit audio to a browser vendor, is outside the frozen MVP, and had no disclosure/consent boundary. The unsupported integration and its incomplete hand-written types are no longer shipped. No compiler/lint checks were disabled.

The original two image lint warnings were fixed using Next Image with explicit dimensions. Lint now rejects warnings. Explicit `next typegen && tsc --noEmit`, production browser regression tests and all-severity npm audit were added to the existing install/lint/build CI. Action revisions are pinned to the exact previously executed v4 SHAs; the runner currently warns about their old declared Node runtime, but executes them on Node 24. Application Node is pinned to major 24 via `.nvmrc` and engines.

## Production regression coverage

1. Landing navigation has no free-text transport.
2. Legacy query values are ignored; synthetic input is not sent through network requests/web storage and clears on reload.
3. User text is escaped; the demonstration ends without invented referrals.
4. Dashboard returns 404 by default, including a query-string opt-in attempt.
5. Explicit synthetic preview renders without a Mapbox token and filters demo requests without runtime errors.
6. Lowercase `/about` resolves and its section links return to the landing page.

## Intentionally open after Phase 0

- Phases 1–2: database, Payload, data-domain separation, ephemeral sessions, redacted logging and checked directory.
- Phases 3–6: explicit adult gate, real deterministic check-in, topic-first optional text, validated safety routing, server-side AI/fallback, Sharing Preview and consented handoff. Current text entry is a labelled visual demo only. No AI costs or external provider calls are introduced.
- Phases 7–8: real authentication/RBAC/organisation isolation, provider lifecycle and anonymous analytics. Synthetic dashboard statuses are historical design placeholders, not the final workflow.
- Phases 9–10: complete EL/EN, accessibility evaluation, safety/privacy domain review, user study and academic validation.
- Production retention, legal/privacy wording, safety matrix, checked Cyprus resources and real-provider pilot requirements remain intentionally unresolved as specified in section 26.
- Optional Mapbox rendering with a real restricted public token requires environment-specific verification; CI exercises the safe no-token path.

Do not call the product production-ready or MVP-complete from this PR. Do not merge automatically.
